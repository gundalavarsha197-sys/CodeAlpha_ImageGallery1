# CodeAlpha_ImageGallery1
# 🌟 Advanced Image Gallery

An interactive and responsive **Image Gallery Web Application** built using **HTML, CSS, and JavaScript**.

## 🚀 Features

* 📱 Responsive grid layout
* 🔍 Lightbox view for enlarged images
* ⬅️➡️ Next/Previous navigation
* ⌨️ Keyboard controls (Arrow keys & Escape)
* 🗂️ Image filtering (Nature, City, All)
* ▶️ Slideshow (Play/Pause)
* 🌙 Dark mode toggle
* ❤️ Like button interaction
* ✨ Smooth hover effects & animations
